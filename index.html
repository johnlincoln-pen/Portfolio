JCrypt: Python message encryption and decryption tool

Python, command line, cryptography. View on GitHub
  • A command-line tool that encrypts a message with a password and decrypts it later. File encryption is on the roadmap.
  • Designed around safe practice: a random salt for every message, a password-based key derivation function (Argon2id or scrypt), then authenticated encryption (AES-GCM or ChaCha20-Poly1305) from a trusted library, never a homemade algorithm.
  • A wrong password or tampered ciphertext is rejected instead of returning corrupted text.
  • Built as an educational and defensive security project, split into CLI, crypto and key-management modules with unit tests planned.

Professional focus

Security failures begin where a system trusts more than it should. My work is to find those points first and help close them.

I am committed to offensive security as a discipline of careful, evidence-based testing. Through freelance VAPT engagements, CTF competitions and continuous lab practice, I have built a methodical approach to finding flaws in access control, business logic and application code.

I treat a finding as complete only when it is documented, rated by risk and reported responsibly, with remediation guidance the owners can act on.

I am building depth on both sides of security: penetration testing to understand how attacks work, and monitoring with Splunk and Wireshark to detect and respond to them.
